# Lab-3.3-Develop-with-Bootstrap
Standardize all front-end projects using Bootstrap to ensure consistency and maintainability. 

# Reflection

## 1. What challenges did you face when refactoring your code to use Bootstrap?

The biggest challenge for me was figuring out which Bootstrap classes could replace the CSS I had already written. I had to look through the Bootstrap utilities and test different classes until the design looked close to my original project.

## 2. How did using Bootstrap utility classes and components simplify your styling process?

Bootstrap made the process a lot easier because I didn't have to write CSS for every little thing. I could use classes like `card`, `p-4`, `fw-bold`, `text-secondary`, and the Bootstrap grid to quickly style and position my elements.

## 3. In what scenarios might you choose not to use Bootstrap and write custom CSS instead?

I would probably use custom CSS if I needed a very specific or unique design that was difficult to create with Bootstrap. I also think custom CSS is useful when I want more control over the design instead of adding a lot of Bootstrap classes to my HTML.
